## 2.2 不等式的求解

在含有未知数的不等式中，能使此不等式成立的未知数的值称为该不等式的解(solution of an inequality). 一个不等式的解的全体所组成的集合称为此不等式的解集（solution set of aninequality). 求不等式解集的过程称为不等式的求解或解不等式(solve an inequality). 将含有相同未知数的多个不等式联立起来，就得到不等式组.．解不等式组就是求不等式组中的所有不等式的解集的交集.

解方程时，往往要先将原先比较复杂的方程变形化为较简单的方程，再通过解这个比较简单的方程来求出原方程的解．同理，解不等式时，常常要通过等价变形，将原不等式化为较简单的不等式或不等式组，从而求得原不等式的解集.

## 2一元二次不等式的求解

在交通事故中，交通管理部门往往通过测量肇事汽车的刹车距离来推断该车辆实施刹车前的行驶速度，并作为断定司机在肇事前是否有超速违章行为的重要参考依据.

假设在某次交通事故中，测得肇事汽车的刹车距离大于20m，试推断该汽车在刹车前的车速是否超过该水泥道路上机动车的限速规定30km/h.在一般情况下，我们可以采用如下数学模型来描述该种型号的汽车在常规水泥路面上的刹车距离d(单位：m)与刹车前的车速v(单位：km/h)之间的关系：

![](images/922edc86b1890cf681568f5eaefde2404f7d051f2e6c1e21694deb3a6dc6dca3.jpg)

$$
d = 0 . 2 0 8 5 v + 0 . 0 0 6 4 v ^ { 2 } .
$$

此刹车案例参考了由吉奥丹诺(F. R.Giordano)等著、叶其孝等译的《数学建模》一书．为便于理解，原始模型中的距离单位英里、英尺换算为千米、米，参数值也做了相应调整.

因此，我们需要通过求解不等式 $0 . 2 0 8 5 v + 0 . 0 0 6 4 v ^ { 2 } > 2 0$ 来判断υ是否大于30km/h．这就是一个一元二次不等式的求解问题.

定义设a、b、c为实数，且 $a \neq 0$ ，形如

$$
a x ^ { 2 } + b x + c > 0 ( < 0 , \geqslant 0 , \sharp \leqslant 0 )
$$

的不等式统称为一元二次不等式（quadratic inequality in one variable).

让我们先来看两个例子.

例3解不等式 $\left( x - 3 \right) \left( x + 1 \right) > 0$

请参照图 2-2-1,在数轴上表示出例3的解集.

解 利用不等式的性质，原不等式等价于两个一次式x一3和x+1同号，即等价于不等式组 $\textstyle { \left\{ \begin{array} { l l } { x + 1 > 0 , } \\ { x - 3 > 0 } \end{array} \right. }$ 或 $\textstyle { \left\{ \begin{array} { l l } { x + 1 < 0 } \\ { x - 3 < 0 . } \end{array} \right. }$

由此得 $\left\{ { \begin{array} { l } { x > - 1 } \\ { x > 3 } \end{array} } \right.$ 或 $\left\{ { \begin{array} { l } { x { \ll } - 1 } \\ { x { \ll } 3 . } \end{array} } \right.$

因此，原不等式的解集为这两个不等式组解集的并集$( - \infty , - 1 ) \bigcup ( 3 , + \infty )$

例4 解不等式 $\left( x - 1 \right) \left( x + 4 \right) < 0$

解 利用不等式的性质，原不等式等价于

$$
\left\{ { x - 1 < 0 } , \atop { \overrightarrow { x } + 4 > 0 }  \right. \bar { \ast } \left\{ { x - 1 > 0 } , \atop { \substack { x + 4 < 0 . } } \right.
$$

由第一组不等式，得 $\stackrel { \scriptscriptstyle x < 1 , } { \mathrm { \Omega } }$ 其解集为(一4，1)；而由第二

组不等式，得 $\textstyle { \left\{ { \begin{array} { l } { x > 1 , } \\ { x < - 4 } \end{array} } \right. }$ 其解集为∅.

因此，原不等式的解集为(一4,1).

下面，我们来讨论如何求解一般的一元二次不等式

$a x ^ { 2 } + b x + c > 0$ 与 $a x ^ { 2 } + b x + c < 0$

不失一般性，我们总假设二次项系数 $_ { \cdot a > 0 }$ .因为当 $a < 0$ 时，只要在原不等式两边同乘一1，并改变不等号的方向，就可以转化为 $a > 0$ 的情形.

通过例3和例4，我们可以发现：一元二次不等式的求解与相应的一元二次方程的求解密切相关.

## 3分式不等式的求解

下面，我们将利用一元一次不等式(组)和一元二次不等式(组)的解法求解一些简单的含有分式的不等式

例如，求解分式不等式 $\frac { a x + b } { c x + d } > 0$ .该不等式等价于分子和分母同号，即 $\left\{ { \begin{array} { l } { a x + b > 0 , } \\ { c x + d > 0 } \end{array} } \right.$ 或 $\left\{ { \begin{array} { l } { a x + b < 0 , } \\ { c x + d < 0 . } \end{array} } \right.$ 这样，就可将分式不等式化为不等式组求解．另外，分子和分母同号也等价于$( a x + b ) ( c x + d ) > 0$ ，这也能将分式不等式化为整式不等式求解.

例10 解不等式 ${ \frac { x + 3 } { 4 - x } } { > } 0 .$

解 原不等式等价于 $x + 3$ 与4一x同号，也就是

$$
\left( x + 3 \right) ( 4 - x ) { \ > } 0 ,
$$

即

$$
\left( x + 3 \right) \left( x - 4 \right) < 0 .
$$

所以，原不等式的解集为(一3，4).

例11 解不等式 ${ \frac { 5 x + 3 } { x - 1 } } { \leqslant } 3 .$

解移项并整理，可将原不等式化为 ${ \frac { 2 x + 6 } { x - 1 } } { \leqslant } 0$ 另外，要使原不等式左边的分式有意义，要求 $x - 1 \neq 0$ 于是，原不等式可转化为

$$
\left\{ { \begin{array} { l } { \left( 2 x + 6 \right) ( x - 1 ) \leqslant 0 , } \\ { x - 1 \neq 0 , } \end{array} } \right.
$$

即

$$
\left\{ { \begin{array} { l } { { - 3 \leqslant x \leqslant 1 , } } \\ { { x \neq 1 . } } \end{array} } \right.
$$

所以，原不等式的解集为 $[ - 3 , 1 )$

例12 解不等式 $\frac { x + 5 } { x ^ { 2 } + 2 x + 3 } { \leqslant } 1$

解对所有实数x，都有 $x ^ { 2 } + 2 x + 3 = ( x + 1 ) ^ { 2 } + 2 > 0$ .在原不等式两边同时乘 $x ^ { 2 } + 2 x + 3$ ，可将原不等式等价地转化为 $x + 5 { \leqslant } x ^ { 2 } + 2 x + 3$
