## 3.3 空间向量的坐标表示

平面向量的坐标表示使得向量的运算可以转化为向量坐标的代数运算，带来了很大的方便．空间向量也可以类似处理．但为此要先建立空间直角坐标系.

## 空间直角坐标系

如图3-3-1，在正方体中，总可以找到从一个顶点出发的三条两两互相垂直的棱，如AB、AD与AA1．受此启示，从空间一点O出发，可以作三条两两互相垂直的坐标轴，建立空间直角坐标系 O-xyz(图 3-3-2).

## 2 空间向量的坐标表示

模仿平面的情况，设 $\vec { i }$ 、j、k分别是x轴、y轴、z轴正方向的单位向量．由于三个坐标轴两两互相垂直，因此这些向量之间的数量积为

$$
\vec { i } ^ { 2 } = \vec { j } ^ { 2 } = \vec { k } ^ { 2 } = 1 , \vec { i } \bullet \vec { j } = \vec { j } \bullet \vec { k } = \vec { k } \bullet \vec { i } = 0 .
$$

给定任意一个向量 ${ \vec { \mathcal { P } } } .$ 我们先通过平移把 $\vec { \mathcal { P } }$ 的起点放到坐标原点O，这时得到的向量 $\overrightarrow { O P }$ 称为 $\vec { \mathcal { P } }$ 的位置向量．设 $\overrightarrow { O P }$ 的终点坐标是 $P ( x , y , z )$ ，则直接记 ${ \vec { \ p } } = ( { \boldsymbol { \it x } } , { \boldsymbol { \it y } } , { \boldsymbol { \it z } } )$ ，并称向量的这种表示法为它的坐标表示.

从图3-3-5 可以看出， $\overrightarrow { O P } = \overrightarrow { O A } + \overrightarrow { A D } + \overrightarrow { D P } = \overrightarrow { O A } + \overrightarrow { O B } + \overrightarrow { O C }$ 而根据点的坐标的定义， $\overrightarrow { O A } = x \overrightarrow { i } , \overrightarrow { O B } = y \overrightarrow { \jmath } , \overrightarrow { O C } = z \overrightarrow { k }$ ，所以${ \vec { p } } = ( x , y , z )$ 的实际含义是

$$
\vec { p } = x \vec { i } + y \vec { j } + z \vec { k } .
$$

有了这个表达式，就可以像平面向量那样推知：如果$( x _ { 1 } , y _ { 1 } , z _ { 1 } ) , ( x _ { 2 } , y _ { 2 } , z _ { 2 } )$ 与 $( x , y , z )$ 是坐标表示的向量，λ是实数，那么

$$
\begin{array} { c } { { ( x _ { 1 } , y _ { 1 } , z _ { 1 } ) \pm ( x _ { 2 } , y _ { 2 } , z _ { 2 } ) = ( x _ { 1 } \pm x _ { 2 } , y _ { 1 } \pm y _ { 2 } , z _ { 1 } \pm z _ { 2 } ) , } } \\ { { { } } } \\ { { \lambda ( x , y , z ) = ( \lambda x , \lambda y , \lambda z ) . } } \end{array}
$$

这说明：把向量用坐标表示后，两个向量相加(减)，等于把它们的对应坐标相加(减)；一个实数乘一个向量，等于把这个实数乘它的坐标.

一个向量 ${ \vec { p } } = ( { \boldsymbol { x } } , { \boldsymbol { y } } , { \boldsymbol { z } } )$ 的模就是它的位置向量 $\overrightarrow { O P }$ 的终点 $P$ 与坐标原点O的距离，所以

$$
| { \overline { { O P } } } | = | ( x , y , z ) | = { \sqrt { x ^ { 2 } + y ^ { 2 } + z ^ { 2 } } } .
$$

如果向量不是由位置向量给出，也可以不通过位置向量得到此向量的坐标表示：设有空间任意两点 $P \left( x _ { 1 } , y _ { 1 } , z _ { 1 } \right)$ 与$Q ( x _ { 2 } , y _ { 2 } , z _ { 2 } )$ ，则

$$
\begin{array} { r l } & { \overrightarrow { P Q } = \overrightarrow { O Q } - \overrightarrow { O P } } \\ & { \quad \quad = ( x _ { 2 } , y _ { 2 } , z _ { 2 } ) - ( x _ { 1 } , y _ { 1 } , z _ { 1 } ) } \\ & { \quad \quad = ( x _ { 2 } - x _ { 1 } , y _ { 2 } - y _ { 1 } , z _ { 2 } - z _ { 1 } ) . } \end{array}
$$

即，一个向量的坐标等于这个向量的终点坐标减去它的起点坐标.

有了上面两个公式，空间任意两点 $P \left( x _ { 1 } , y _ { 1 } , z _ { 1 } \right)$ 与$Q ( x _ { 2 } , y _ { 2 } , z _ { 2 } )$ 的距离就很容易求出了，因为这两点的距离$| P Q |$ 等于向量 $\overrightarrow { P Q } = ( x _ { 2 } - x _ { 1 } , y _ { 2 } - y _ { 1 } , z _ { 2 } - z _ { 1 } )$ 的模 $| \overrightarrow { P Q } |$ ．由此得到

$$
| \overrightarrow { P Q } | = \sqrt { ( x _ { 2 } - x _ { 1 } ) ^ { 2 } + ( y _ { 2 } - y _ { 1 } ) ^ { 2 } + ( z _ { 2 } - z _ { 1 } ) ^ { 2 } } .
$$

最后，我们看两个空间向量的数量积如何用坐标表示.

给定两个向量 $\vec { a } = ( \boldsymbol { x } _ { 1 } , \boldsymbol { y } _ { 1 } , \boldsymbol { z } _ { 1 } )$ 与 $\vec { b } = ( x _ { 2 } , y _ { 2 } , z _ { 2 } )$ ，把它们写成坐标轴正方向的单位向量的线性组合，就有 $\vec { a } = x _ { 1 } \vec { i } + y _ { 1 } \vec { j } +$ $z _ { 1 } \vec { k }$ 与 $\vec { b } = x _ { 2 } \vec { \imath } + y _ { 2 } \vec { \jmath } + z _ { 2 } \vec { k }$ ，于是

$$
\vec { a } \bullet \vec { b } = ( x _ { 1 } \vec { i } + y _ { 1 } \vec { j } + z _ { 1 } \vec { k } ) \bullet ( x _ { 2 } \vec { i } + y _ { 2 } \vec { j } + z _ { 2 } \vec { k } ) .
$$

对上式用分配律展开计算，并注意到 $\vec { i } , \vec { j }$ 、k是两两互相垂直的向量，且 $\vec { i } ^ { 2 } = \vec { j } ^ { 2 } = \vec { k } ^ { 2 } = 1$ ，所以

$$
\vec { a } \bullet \vec { b } = x _ { 1 } x _ { 2 } \vec { i } ^ { 2 } + y _ { 1 } y _ { 2 } \vec { j } ^ { 2 } + z _ { 1 } z _ { 2 } \vec { k } ^ { 2 } = x _ { 1 } x _ { 2 } + y _ { 1 } y _ { 2 } + z _ { 1 } z _ { 2 } .
$$

这就是我们所需要的两向量数量积公式

$$
( x _ { 1 } , y _ { 1 } , z _ { 1 } ) \bullet ( x _ { 2 } , y _ { 2 } , z _ { 2 } ) = x _ { 1 } x _ { 2 } + y _ { 1 } y _ { 2 } + z _ { 1 } z _ { 2 } .
$$

两个非零向量 $\vec { a } = ( \boldsymbol { x } _ { 1 } , \boldsymbol { y } _ { 1 } , \boldsymbol { z } _ { 1 } )$ 与 $\vec { b } = ( x _ { 2 } , y _ { 2 } , z _ { 2 } )$ 夹角的余弦公式是

$$
\cos \langle \vec { a } , \vec { b } \rangle = \frac { x _ { 1 } x _ { 2 } + y _ { 1 } y _ { 2 } + z _ { 1 } z _ { 2 } } { \sqrt { x _ { 1 } ^ { 2 } + y _ { 1 } ^ { 2 } + z _ { 1 } ^ { 2 } } \sqrt { x _ { 2 } ^ { 2 } + y _ { 2 } ^ { 2 } + z _ { 2 } ^ { 2 } } } .
$$

![](images/95d25c81cc438dcb126a240aec0d957ea1ecf7220d3acdb5587e480f6c93fb53.jpg)  
图 3-3-7

从两向量夹角的余弦公式和两向量平行的充要条件可分别得到两个非零向量垂直与平行的充要条件：

$$
{ \vec { a } } \bot { \vec { b } } \Longleftrightarrow x _ { 1 } x _ { 2 } + y _ { 1 } y _ { 2 } + z _ { 1 } z _ { 2 } = 0 ;
$$

$\vec { a } / / \vec { b } \Longleftrightarrow$ 存在 $\lambda \in \mathbf { R }$ ，使得 $x _ { 1 } = \lambda x _ { 2 } , y _ { 1 } = \lambda y _ { 2 } , z _ { 1 } = \lambda z _ { 2 } .$

例2 如图3-3-7，给定正方体 $A B C D / / B _ { 1 } B _ { 1 } C _ { 1 } D _ { 1 }$

(1) 求对角线 $C A _ { 1 }$ 与CA所成角的余弦值；

(2) 求证： $C A _ { 1 } \bot B D$

解（1）以点A为坐标原点，分别以射线 $A B , ~ A D , ~ A A _ { 1 }$ 为x轴、y轴、z轴的正半轴，建立空间直角坐标系．设正方体的棱长为a，可得有关点的坐标分别为 $B \left( a , 0 , 0 \right) , ~ D \left( 0 , a , 0 \right)$ $C ( a , a , 0 ) , A _ { 1 } ( 0 , 0 , a )$ ，从而 $\overrightarrow { C A } = \left( - a , - a , 0 \right) , \overrightarrow { C A _ { 1 } } =$ $( - a , - a , a )$ ．于是

$$
\cos \langle \overrightarrow { C A _ { 1 } } , \overrightarrow { C A } \rangle = \frac { \overrightarrow { C A _ { 1 } } \cdot \overrightarrow { C A } } { \vert \overrightarrow { C A _ { 1 } } \vert \vert \overrightarrow { C A } \vert } = \frac { a ^ { 2 } + a ^ { 2 } } { \sqrt { a ^ { 2 } + a ^ { 2 } } \sqrt { a ^ { 2 } + a ^ { 2 } + a ^ { 2 } } } = \frac { 2 } { \sqrt { 6 } } = \frac { \sqrt { 6 } } { 3 } .
$$

所以，对角线 $C A _ { 1 }$ 与CA 所成角的余弦值为 $\cdot \frac { \sqrt { 6 } } { 3 }$

(2) 证明：由 $| \overrightarrow { C A _ { 1 } } = \left( - a , - a , a \right) , \overrightarrow { B D } = \left( - a , a , 0 \right)$ ，得

$$
\overrightarrow { C A _ { 1 } } \cdot \overrightarrow { B D } = ( - a ) ^ { 2 } + ( - a ) a + 0 = 0 .
$$

所以， $C A _ { 1 } \bot B D$
