定义 如果一个数列从第2项起，每一项与其前一项的比都等于同一个非零常数，这个数列就叫做等比数列（geometricsequence)，而这个常数叫做等比数列的公比(common ratio).公比通常用小写字母 $q ~ \left( q \neq 0 \right)$ 表示.

在两个非零实数a与b中间插入一个数G，使a，G，b成等比数列．根据等比数列的定义，有 ${ \frac { G } { a } } = { \frac { b } { G } }$ ，从而 $G ^ { 2 } = a b$ ，即$G { = } \sqrt { a b }$ 或 $G = - { \sqrt { a b } }$ ．这两种情形下，a，G，b均为等比数列. 此时，G叫做a与b的等比中项.

如果三个数成等比数列，那么等比中项的平方必等于其前后两项的积.

根据等比数列的定义，以 $a _ { 1 }$ 为首项、以q为公比的等比数列 $\{ a _ { n } \ \}$ 满足 $\scriptstyle \cdot { \frac { a _ { n } } { a _ { n - 1 } } } = q ( n \geq 2 )$ ．因此，当 $n { \geqslant } 2$ 时，有

$$
\begin{array} { r } { \frac { a _ { 2 } } { a _ { 1 } } { = } q , \ \frac { a _ { 3 } } { a _ { 2 } } { = } q , \ \frac { a _ { 4 } } { a _ { 3 } } { = } q , \ \cdots , \ \frac { a _ { n } } { a _ { n - 1 } } { = } q . } \end{array}
$$

由此可得， ${ \frac { a _ { n } } { a _ { 1 } } } = q ^ { n - 1 }$ ．所以， $a _ { n } = a _ { 1 } q ^ { n - 1 } ~ ( n \geq 2 )$ ．而当 $n = 1$ 时，上面的等式也显然成立.

因此，当n为正整数时，等比数列 $\left\{ a _ { n } \right\}$ 的第 n 项可表示为

$$
a _ { n } = a _ { 1 } q ^ { n - 1 } .
$$

这称为等比数列 $\left\{ a _ { n } \right\}$ 的通项公式.

一般地，设等比数列 $\left\{ a _ { n } \right\}$ 的公比为 q，其前n项和为

$$
\displaystyle { S _ { n } = a _ { 1 } + a _ { 1 } q + a _ { 1 } q ^ { 2 } + \cdots + a _ { 1 } q ^ { n - 1 } } .
$$

将上式两边同乘公比q，可得

$$
q S _ { n } = a _ { 1 } q + a _ { 1 } q ^ { 2 } + a _ { 1 } q ^ { 3 } + \cdots + a _ { 1 } q ^ { n } .
$$

将两式相减，可得

$$
S _ { n } - q S _ { n } = a _ { 1 } - a _ { 1 } q ^ { n } ,
$$

即

$$
( 1 - q ) S _ { n } = a _ { 1 } ( 1 - q ^ { n } ) .
$$

由此得到，当 $q \not = 1$ 时，等比数列 $\left\{ a _ { n } \right\}$ 的前n项和为

$$
S _ { n } { = } \frac { a _ { 1 } ( 1 { - } q ^ { n } ) } { 1 { - } q } .
$$

综上所述，可以得到以 $a _ { 1 }$ 为首项、以 $q \ ( q { \neq } 1 )$ 为公比的等比数列的前n 项和公式为

$$
S _ { n } { = } \frac { a _ { 1 } ( 1 { - } q ^ { n } ) } { 1 { - } q } ~ ( q { \neq } 1 ) .
$$

因为 $a _ { n } = a _ { 1 } q ^ { n - 1 }$ ，所以上式又可写为

$$
S _ { n } { = } \frac { a _ { 1 } { - } a _ { n } q } { 1 { - } q } \ \left( q { \neq } 1 \right) .
$$

而当 $q = 1$ 时，因为 $a _ { 1 } = a _ { 2 } = \cdots = a _ { n }$ ，所以 $S _ { n } = n a _ { 1 }$
