## 直线的倾斜角1.1与斜率

设平面直角坐标系中有一条直线l，我们如何确定该直线在坐标系中的位置并把它描述出来呢？

![](images/7b0d319e5f8c4b4dd5f241245c1fefc82524a9c2adb02c72aeed89f7b99a541e.jpg)  
图 1-1-1

在平面直角坐标系中，已经有了两条互相垂直的直线，即两条坐标轴，我们只要能确定直线l与其中一条坐标轴的相对位置，就能描述出该直线在坐标系中的位置．不妨先设直线l与x轴相交于点A，如图1-1-1所示．将x轴绕点A沿逆时针方向旋转到与l重合时所转过的最小正角θ叫做直线l的倾斜角(angleof inclination). 显然， $\quad 0 < \theta < \pi .$ 当直线l与x轴平行或重合时，规定倾斜角为0，这样，直线l的倾斜角的取值范围就可扩大为$0 \leqslant \theta < \pi$ ，即 $\theta \in [ 0 , \pi )$ ．特别地，当倾斜角 $\theta = \frac { \pi } { 2 }$ 时，直线l与x 轴垂直.

如果知道了直线l的倾斜角以及它经过的一个确定的点，那么就准确地给出了直线l在坐标系中的位置．由于倾斜角难以直接用坐标表示出来，而倾斜角的三角函数与坐标的关系更为密切．为此，我们引进一个新的概念：当直线l的倾斜角 $\theta { \neq } \frac { \pi } { 2 }$ 时，定义tanθ为直线l的斜率(slope)，常用字母k表示，即 $k = \tan \theta$ 当 $\scriptstyle \theta = { \frac { \pi } { 2 } }$ ，即l与x轴垂直时，我们说直线l的斜率不存在.

我们来看如何用坐标表示一条直线的斜率.

设直线l经过不同的两点 $A ( x _ { 1 } , y _ { 1 } )$ $B ( x _ { 2 } , y _ { 2 } )$ .当 ${ \boldsymbol { x } } _ { 1 } = { \boldsymbol { x } } _ { 2 }$ 时，直线l与x轴垂直(图1-1-2)，此时，直线l的倾斜角 $\theta { = } \frac { \pi } { 2 }$ 斜率不存在.

当 $x _ { 1 } \neq x _ { 2 }$ 时，不妨设 $x _ { 1 } { < } x _ { 2 }$ ，有以下3种情况：

(1）若 $y _ { 1 } { < } y _ { 2 }$ ，则l的倾斜角θ为锐角．如图1-1-3，作直角三角形ABC，可得 $k = \frac { y _ { 2 } - y _ { 1 } } { x _ { 2 } - x _ { 1 } }$

(2)若 $y _ { 1 } = y _ { 2 }$ ，则直线l与x轴平行或重合，所以l的倾斜角$\theta = 0$ ，斜率也等于0，这就是(1)结果中令 $y _ { 1 } = y _ { 2 }$ 所得的值.

(3）若 $y _ { 1 } > y _ { 2 }$ ，则直线l的倾斜角θ为钝角．如图 $1 - 1 - 4$ 同样作直角三角形ABC，则 $\angle A B C = \pi - \theta .$ 在直角三角形ABC中，因为 $\tan \angle A B C = { \frac { | C A | } { | C B | } } = { \frac { y _ { 1 } - y _ { 2 } } { x _ { 2 } - x _ { 1 } } }$ ，所以 $\tan \ ( \pi - \theta ) =$ $\frac { y _ { 1 } - y _ { 2 } } { x _ { 2 } - x _ { 1 } }$ ，由此得 $\tan \theta = { \frac { y _ { 2 } - y _ { 1 } } { x _ { 2 } - x _ { 1 } } }$ ，即 $k = \frac { y _ { 2 } - y _ { 1 } } { x _ { 2 } - x _ { 1 } }$ ，这与(1)中的结果相同.

综上所述，可以得到：在平面直角坐标系中，经过不同的两点 $A ( x _ { 1 } , y _ { 1 } )$ 、B $( x _ { 2 } , y _ { 2 } ) ( x _ { 1 } \mp x _ { 2 } )$ 的直线l的斜率为

$$
k { = } \frac { y _ { 2 } { - } y _ { 1 } } { x _ { 2 } { - } x _ { 1 } } .
$$

例1 已知直线l经过点 $A ( - 1 , - 1 )$ 、B(2,3)，求它的斜率与倾斜角.

解 设直线l的斜率为k，倾斜角为θ，则

$$
k = \tan \theta { = } \frac { 3 - ( - 1 ) } { 2 - ( - 1 ) } { = } \frac { 4 } { 3 } ,
$$

从而 $\theta = \arctan { \frac { 4 } { 3 } } .$

例2求一次函数 $y = k x + b ( k \neq 0 )$ 所表示直线的斜率.

解 设一次函数 $y = k x + b ( k \neq 0 )$ 的图像是直线l.在函数表达式中，x的值分别取 $x _ { 1 } = 0$ 及 $x _ { 2 } = 1$ ，得 $y _ { 1 } = b$ 及 $y _ { 2 } = k + b$ 所以， $A \left( 0 , b \right)$ 与 $B ( 1 , k + b )$ 是直线l上的两点．依据斜率公式，得直线l的斜率为

![](images/dd2d5ad455c8fe9f8fb3e016e1a815516201cc417847f935939de936870fe164.jpg)

一次函数y =kx+b(k≠0)的一次项系数k就是其对应直线的斜率.

$$
{ \frac { y _ { 2 } - y _ { 1 } } { x _ { 2 } - x _ { 1 } } } { = } { \frac { ( k + b ) - b } { 1 - 0 } } { = } k .
$$

例3 已知三点A(—1,2)、B(3,4)、 $C \left( x , y \right)$ 共线，求点 C的坐标x 与y 所满足的关系式

解因为A、B两点的横坐标不同，所以直线AB的斜率是

$$
k = \frac { 4 - 2 } { 3 - ( - 1 ) } = \frac { 1 } { 2 } .
$$

又由题设知，点C在直线AB上，即AB与AC是同一条直线.

当点C与点A不重合时，用A、C两点的坐标表示斜率得

$$
k = \frac { y - 2 } { x - ( - 1 ) } { = } \frac { y - 2 } { x + 1 } ,
$$

此时 x 与y要满足的关系式是 $\cdot \frac { y - 2 } { x + 1 } = \frac { 1 } { 2 }$ ，变形得

$$
y - 2 { = } \frac { 1 } { 2 } ( x { + } 1 ) .
$$

当点C与点A重合时，点C的坐标也满足上式.

所以，x与y满足的关系式是 $y - 2 { = } \frac 1 2 ( x { + } 1 )$
