# 余弦函数的图像7.2与性质

我们知道，对于任意一个给定的实数x，都有唯一确定的余弦值cosx与之对应.按照这个对应关系所建立的函数叫做余弦函数，记作 $y = \cos x$ ． 余弦函数的定义域是实数集R

## 余弦函数的图像

怎样作余弦函数 $y = \cos x$ 的图像呢?

当然，我们可以像对正弦函数 $y = \sin { x }$ 一样，把任意角x的余弦值cosx用角的终边与单位圆的交点的横坐标表示，用描点法作出余弦函数的图像.

但是，由于已经知道了正弦函数 $y = \sin { x }$ 的图像，我们可以简便地利用余弦函数与正弦函数的关系来作出余弦函数的图像．事实上，由于 $\cos x = \sin \left( x + { \frac { \pi } { 2 } } \right)$ 对任意的 $x \in \mathbf { R }$ 都成立，因此余弦函数 $y = \cos x$ 与函数 $y = \sin \left( x + { \frac { \pi } { 2 } } \right)$ 是同一个函数，从而它们的图像相同．由于将正弦函数 $y = \sin { x }$ 的图像向左平移 $\frac { \pi } { 2 }$ 就得到函数 $y = \sin \left( x + { \frac { \pi } { 2 } } \right)$ 的图像，即 $y = \cos x$ 的图像(图7-2-1).余弦函数的图像通常称为余弦曲线.

$$

## 2 余弦函数的性质

利用余弦函数 $y = \cos x$ 与正弦函数 $y = \sin { x }$ 的关系 $\cos x =$ $\sin \left( x + { \frac { \pi } { 2 } } \right)$ ，由正弦函数的性质就容易推出余弦函数的性质：

（1）余弦函数 $y = \cos x$ 是周期函数，2k $\cdot \pi \ ( k \in { \bf Z } , \ k \ne 0 )$ 均是它的周期，而2π是它的最小正周期.

(2) 余弦函数 $y = \cos x$ 的值域是 $[ - 1 , 1 ]$

当且仅当 $x = 2 k \pi \left( k \in \mathbf { Z } \right)$ 时， $y = \cos x$ 取得最大值1；而当且仅当 $x = 2 k \pi + \pi \left( k \in \mathbf { Z } \right)$ 时， $y = \cos x$ 取得最小值一1.

(3) 余弦函数 $y = \cos x$ 是偶函数，其图像关于y轴对称.

(4) 余弦函数 $y = \cos x$ 在区间 $[ 2 k \pi - \pi , 2 k \pi ] ( k \in { \bf Z } )$ 上是严格增函数，而在区间 $[ 2 k \pi , 2 k \pi + \pi ] ( k \in { \bf Z } )$ 上是严格减函数.

例1 求下列函数的最大值与最小值，并求出取得最大值和最小值时所有x的值：

(1) $y = \cos ^ { 2 } x - 4 \cos x + 1 , \ x \in \mathbf { R }$

(2) $y = \cos { \frac { x } { 2 } } , \ x \in \left[ - { \frac { 4 \pi } { 3 } } , { \frac { \pi } { 2 } } \right] .$

解（1）令 $t = \cos { \mathcal { x } }$ ，则

$$
y = t ^ { 2 } - 4 t + 1 = ( t - 2 ) ^ { 2 } - 3 , \ t \in [ - 1 , 1 ] .
$$

当 $- 1 { \leqslant } t { \leqslant } 1$ 时，有 $- 3 { \leqslant } t - 2 { \leqslant } - 1$ ，从而 $1 { \leqslant } ( t - 2 ) ^ { 2 } { \leqslant } 9$ 于是 $- 2 { \leqslant } ( t - 2 ) ^ { 2 } - 3 { \leqslant } 6$

这样，y的最大值是6，此时 $t - 2 = - 3 , \ t = - 1$ ，即

$$
\cos x = - 1 , x = 2 k \pi + \pi \left( k \in \mathbf { Z } \right) ;
$$

而y的最小值是一2，此时 $t - 2 { = } - 1 , \ t = 1$ ，即

$$
\cos x = 1 , x = 2 k \pi ( k \in { \bf Z } ) .
$$

(2) 令 $u = \frac { x } { 2 }$ ，则

$$
y = \cos u .
$$

由 $x \in \left[ - \frac { 4 \pi } { 3 } , \frac { \pi } { 2 } \right]$ ，有 $- { \frac { 2 \pi } { 3 } } { \leqslant } { \frac { x } { 2 } } { \leqslant } { \frac { \pi } { 4 } }$ ，即 $u \in \left\lceil - { \frac { 2 \pi } { 3 } } , { \frac { \pi } { 4 } } \right\rceil$

由余弦函数的性质可知， $y = \cos u$ 在区间 $\left[ - \frac { 2 \pi } { 3 } , 0 \right]$ 上是 $\overrightarrow { j } ^ { \mathrm { I L } }$

格增函数，而在 $\left[ 0 , { \frac { \pi } { 4 } } \right]$ 上是严格减函数.

又因为

$$
\cos \Big ( - \frac { 2 \pi } { 3 } \Big ) = \cos \frac { 2 \pi } { 3 } = - \frac { 1 } { 2 } , \cos 0 = 1 , \cos \frac { \pi } { 4 } = \frac { \sqrt { 2 } } { 2 } ,
$$

所以y的最大值是1，此时 $u = 0$ ，即 $\frac { x } { 2 } = 0$ ，从而 $x = 0 ; y$ 的最小值是 $- \frac { 1 } { 2 }$ ，此时 $u = - { \frac { 2 \pi } { 3 } }$ ，即 $\frac { x } { 2 } { = } - \frac { 2 \pi } { 3 }$ ，从而 $x = - { \frac { 4 \pi } { 3 } } .$

例2 求函数 $y = 2 \cos { \left( 2 x - \frac { \pi } { 3 } \right) }$ 的最小正周期及单调增区间.

解因为

$$
\begin{array} { c } { { 2 \cos \left( 2 x - \displaystyle \frac { \pi } { 3 } \right) { = } 2 \sin \left[ \displaystyle \frac { \pi } { 2 } { + } \Big ( 2 x { - } \displaystyle - \frac { \pi } { 3 } \Big ) \right] } } \\ { { { } } } \\ { { { } = } 2 \sin \left( 2 x { + } \displaystyle \frac { \pi } { 6 } \right) , } \end{array}
$$

而 $y = 2 \ \sin \left( 2 x + { \frac { \pi } { 6 } } \right)$ 的最小正周期是 ${ \frac { 2 \pi } { 2 } } = \pi$ ，所以函数$y = 2 \cos \left( 2 x - \frac { \pi } { 3 } \right)$ 的最小正周期是π.

由余弦函数的单调性可知，当 $2 k \pi - \pi \leqslant 2 x - \frac { \pi } { 3 } \leqslant 2 k \pi$ $( k \in \mathbf { Z } )$ ，即 $k \pi - \frac { \pi } { 3 } \leqslant x \leqslant k \pi + \frac { \pi } { 6 } \left( k \in \mathbf { Z } \right)$ 时，函数 $y =$ $2 \cos \left( 2 x - { \frac { \pi } { 3 } } \right)$ 是 $\overrightarrow { j } ^ { \mathrm { { I L } } }$ 格增函数，即此函数的单调增区间是$\left[ k \pi - { \frac { \pi } { 3 } } , k \pi + { \frac { \pi } { 6 } } \right] \left( k \in { \bf Z } \right)$
