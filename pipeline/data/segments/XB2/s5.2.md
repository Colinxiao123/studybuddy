## 5.2 导数的运算

在本章5.1节的学习中，我们已经了解到一个函数在某点处导数的概念．从导数的定义中不难发现：给定函数 $y = f ( x )$ ，在导数存在的前提下，对于不同的 $x _ { 0 }$ ，总有一个确定的导数值$f ^ { \prime } ( x _ { 0 } )$ 与之对应．换句话说，如果用x表示自变量，那么 $y ^ { \prime } =$ $f ^ { \prime } ( x )$ 也是一个关于x的函数．称为函数 $y = f \left( x \right)$ 的导函数(derivedfunction，也简称为导数)，其中

$$
f ^ { \prime } ( x ) { = } \operatorname* { l i m } _ { h \to 0 } { \frac { f ( x + h ) - f ( x ) } { h } } .
$$

求一个函数的导(函)数的过程常简称为求导.

如果能够求出函数 $y = f ( x )$ 的导数 $y ^ { \prime } { = } f ^ { \prime } ( x )$ ，那么求该函数在某点处导数的问题就可以通过简单的代入求值来解决.

## 基本初等函数的导数

![](images/a95a530fc7307bacd856d2acffa7ff0b0166cb4c2e767722735395f866ed017c.jpg)

常数函数、幂函数、指数函数、对数函数、三角函数、反三角函数被称为基本初等函数.

根据导数的定义，可以求出一些基本初等函数的导数.

例1 求常数函数 $y = C$ 的导数.

解记 $f ( x ) { = } C $ 当 $h \neq 0$ 时，

$$
{ \frac { f ( x + h ) - f ( x ) } { h } } = = { \frac { C - C } { h } } = { \frac { 0 } { h } } = 0 .
$$

因此，当h趋近于0时， $f ^ { \prime } ( x ) { = } \operatorname* { l i m } _ { h \to 0 } 0 { = } 0 .$

对于例1中的函数 $y = f ( x )$ ，坐标平面中的相应曲线 $y =$ $f ( x )$ 是平行于x轴的直线 $y = C$ ，连接该直线上任何两点的割线都是这条直线本身，从而该直线上任何一点处的切线也是这条直线本身．由此可见，该直线上任何一点处的切线的斜率都是0，即对任何给定的 $x _ { 0 }$ ，都有 $f ^ { \prime } ( x _ { 0 } ) { = } 0$ 由此推出 $\boldsymbol { f } ^ { \prime } ( \boldsymbol { x } ) = 0$ ．这就从导数的几何意义诠释了例1的结论.

类似的分析适用于函数 $y = k x + b$ .记 $f ( x ) = k x + b$ .直线 $y$ $= k x + b$ 上任何一点处的切线都是这条直线本身，从而都具有斜率k，即对任何给定的 $x _ { 0 }$ ，都有 $f ^ { ' } ( x _ { 0 } ) = k$ ．由此推出 $f ^ { \prime } ( x ) = k$ 这个从几何上推出的结论也可用导数的定义来验证

例2求函数 ${ \boldsymbol { y } } = { \boldsymbol { k } } { \boldsymbol { x } } + { \boldsymbol { b } } $ 的导数.

解记 $f ( x ) = k x + b$ .当 $h \neq 0$ 时，

$$
{ \frac { f ( x + h ) - f ( x ) } { h } } = { \frac { k \left( x + h \right) + b - \left( k x + b \right) } { h } } = { \frac { k h } { h } } = k .
$$

因此，当h趋近于0时， $f ^ { \prime } ( x ) = \operatorname* { l i m } _ { h \to 0 } h = k$

例3求下列幂函数 $y = f ( x )$ 的导数，其中：

(1) $f ( x ) = x ^ { 2 } ;$ (2) $f ( x ) { = } x ^ { - 1 }$ (3) $f ( x ) = x ^ { \frac { 1 } { 2 } }$

解（1）当 $h \neq 0$ 时，

$$
{ \frac { f ( x + h ) - f ( x ) } { h } } = { \frac { ( x + h ) ^ { 2 } - x ^ { 2 } } { h } } = { \frac { 2 x h + h ^ { 2 } } { h } } = 2 x + h .
$$

因此，当h趋近于0时， $f ^ { \prime } ( x ) { = } \operatorname* { l i m } _ { h \to 0 } { ( } 2 x + h { ) } { = } 2 x .$

(2)当 $h \neq 0$ 时，

$$
{ \frac { f ( x + h ) - f ( x ) } { h } } = { \frac { ( x + h ) ^ { - 1 } - x ^ { - 1 } } { h } } = { \frac { x - ( x + h ) } { x ( x + h ) h } } = { \frac { - 1 } { x ( x + h ) } } .
$$

因此，当h趋近于0时， $f ^ { \prime } ( x ) = \operatorname* { l i m } _ { h \to 0 } { \frac { - 1 } { x ( x + h ) } } = - { \frac { 1 } { x ^ { 2 } } } = - x ^ { - 2 } .$

(3) 当 $h \neq 0$ 时，

$$
{ \begin{array} { r l } { { \frac { f ( x + h ) - f ( x ) } { h } } = { \frac { \sqrt { x + h } - { \sqrt { x } } } { h } } } \\ & { \qquad = { \frac { ( { \sqrt { x + h } } - { \sqrt { x } } ) ( { \sqrt { x + h } } + { \sqrt { x } } ) } { h ( { \sqrt { x + h } } + { \sqrt { x } } ) } } } \\ & { \qquad = { \frac { 1 } { \sqrt { x + h } + { \sqrt { x } } } } . } \end{array} }
$$

因此，当h趋近于0时， $f ^ { \prime } ( x ) { = } \operatorname* { l i m } _ { h \to 0 } { \frac { 1 } { \sqrt { x + h } + \sqrt { x } } } { = } { \frac { 1 } { 2 \sqrt { x } } } { = } { \frac { 1 } { 2 } } x ^ { - { \frac { 1 } { 2 } } } .$

## 3简单复合函数的导数

在本节例7第(3)小题中，为了求 $f ( x ) = ( x { - } 2 ) ^ { 2 }$ 的导数，我们先借助于完全平方公式将 $( x { - } 2 ) ^ { 2 }$ 化为 $x ^ { 2 } - 4 x + 4$ ，再利用导数四则运算法则求导．从另一个角度看，函数 $y = ( x - 2 ) ^ { 2 }$ 也可以看作由两个函数 $y = u ^ { 2 } , \ u = x - 2 ^ {  }$ 套”在一起所构成的新函数．像这样，如果一个函数 $y { = } f ( u )$ 的自变量u又是另一个变量x的函数 $u = g \left( x \right)$ 那么就可将y直接看作变量x的函数而得到一个新函数y=$f ( g ( x ) )$ ，这个新函数被称为两个函数的复合函数(composite function).

在对复合函数求导数时，往往不是把两个预先给定的函数先复合成较复杂的函数，然后直接求导，而是反过来，先引进一个中间变量，把原来的函数看作两个相对简单的函数的复合，再利用复合函数的求导法则求其导数，从而使求导过程得到简化．例如，函数 $y = ( x - 2 ) ^ { 2 }$ 可看作由函数 $\scriptstyle y = u ^ { 2 }$ 与 $u = x - 2$ 复合而成，而函数 $y = \sin { 2 x }$ 可看作由函数 $y { = } \sin u$ 与 $u { = } 2 x$ 复合而成.

我们不讨论一般复合函数的求导问题，仅考虑由 $y { = } f ( u )$ 与$u = a x + b ( a \neq 0 )$ 复合而成的 $y = f ( a x + b )$ 型复合函数的求导法则.因为当 $h \neq 0$ 时，有

$$
{ \frac { f ( a ( x + h ) + b ) - f ( a x + b ) } { h } } = a \ \cdot \ { \frac { f ( u + a h ) - f ( u ) } { a h } } ,
$$

且注意到h趋近于0当且仅当ah趋近于0，所以

$$
\operatorname* { l i m } _ { h \to 0 } { \frac { f ( a \left( x + h \right) + b ) - f ( a x + b ) } { h } } { = } a \operatorname* { l i m } _ { a h \to 0 } { \frac { f ( u + a h ) - f ( u ) } { a h } } .
$$

这就给出了 $y = f ( a x + b )$ 型复合函数的如下求导法则：

(11) $( f ( a x + b ) ) ^ { \prime } { = } a f ^ { \prime } ( u )$ ，其中 $u = a x + b .$
