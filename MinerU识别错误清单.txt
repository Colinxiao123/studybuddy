【1】位置：知识点 KP-FUNC-0004 · aliases 字段
          （FUNC/nodes.json 第 60 行起，aliases 位于第 63 行）
    错误原因：MinerU 直排式根号识别被沿用。同一公式在教材片段
              BX1/s3.1.md 第 89 行的"奇数"分支被识别为直排文本"√aⁿ =a"，
              "偶数"分支却输出规范 LaTeX，一条公式两种识别；本条别名
              沿用了前者的直排形态（ⁿ 为上标字符 U+207F）
    错误内容：√(aⁿ) 的化简
    人工校验：$\sqrt[n]{a^n}$ 的化简（或写作"n 次根式的化简"）

【2】位置：知识点 KP-TRIG-0002 · aliases 字段（TRIG/nodes.json 第 35 行起）
    错误原因：教材"表 6-1"列头（30°、45°、60°）誊写时丢失分隔符，
              "30°45°60°"连读易误读
    错误内容：30°45°60°的三角函数值
    人工校验：特殊角 30°、45°、60° 的三角函数值

---------------- 一、字符腐蚀（7 条） ----------------

【1】位置：BX2/s9.4.md 第 225 行
    错误原因：虚数单位 i（斜体）被识别为"•1"
    错误内容：……它的三次方根是 $\cos { \frac { 2 k \pi } { 3 } } +$ •1 $\sin { \frac { 2 k \pi } { 3 } }$ ……
    人工校验：……它的三次方根是 $\cos\frac{2k\pi}{3}+\mathrm{i}\sin\frac{2k\pi}{3}$ ……

【2】位置：BX2/s9.4.md 第 22 行
    错误原因：多余乱码"−♯Z"（\sharp 残留），非教材内容
    错误内容：复数的任意一个辐角θ与复数的模 $r=|z|=\sqrt{a^2+b^2} - \sharp\mathbb{Z}$ 就完全确定了复数
    人工校验：复数的任意一个辐角θ与复数的模 $r=|z|=\sqrt{a^2+b^2}$ 就完全确定了复数

【3】位置：BX2/s9.4.md 第 38 行
    错误原因：虚数单位 i 被识别为带点的 1（\dot{1}）
    错误内容：(1) $\sqrt{3}+\dot{1}$
    人工校验：(1) $\sqrt{3}+\mathrm{i}$

【4】位置：BX1/s1.2.md 第 141 行
    错误原因：根号内被开方数识别失败，输出乱码"∑"
    错误内容：下一小节将给出√∑是无理数的证明
    人工校验：下一小节将给出√2是无理数的证明

【5】位置：BX2/s9.1.md 第 53 行
    错误原因：同上（√ 后被开方数乱码）
    错误内容：与初中学过的形如 a+b√∑的根式之间的运算作个类比
    人工校验：被开方数丢失，据上下文应为 a+b√2（须对照原书核实）

【6】位置：BX2/s8.2.md 第 175 行
    错误原因：综合腐蚀（减号变破折号、向量记号丢失、b² 缺字）
    错误内容：由(1)类似可证：(—b)²=a²-2ā·b+²
    人工校验：由(1)类似可证：(-b)²=a²-2a·b+b²

【7】位置：BX2/s9.4.md 第 301 行
    错误原因：文字被识别为 \boxplus 空盒结构（识别失败占位）
    错误内容：即把 $x^3$（\boxplus 乱码结构）成了两数之和
    人工校验：即把 x³ 改写成了两数之和

---------------- 三、其他识别错误（2 条） ----------------

【15】位置：BX1/s3.1.md 第 89 行
    错误原因：同一公式两种识别——"奇数"分支被识别为直排文本，
              "偶数"分支为规范 LaTeX（本条即知识点 KP-FUNC-0004 别名的来源）
